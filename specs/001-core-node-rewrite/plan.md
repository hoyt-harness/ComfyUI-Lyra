# Implementation Plan: Core Node Rewrite

**Branch**: `001-core-node-rewrite` | **Date**: 2026-09-04 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-core-node-rewrite/spec.md`

## Summary

Rebuild ComfyUI-Lyra from the upstream hard fork into a clean, production-ready
Orpheus TTS custom node. Primary deliverables: (1) SoX dependency eliminated,
replaced by pedalboard for all audio effects; (2) node architecture refactored
into `nodes/` and `core/` subdirectories; (3) runtime and dev dependencies
split so CI runs lint without torch; (4) all three nodes pass validation
scenarios in ComfyUI Desktop.

## Technical Context

**Language/Version**: Python 3.10+

**Primary Dependencies**:
- Inference: transformers, snac, torch (runtime only)
- Audio effects: pedalboard (replaces SoX entirely)
- Audio I/O: soundfile, numpy
- Dev: ruff, pyright, safety, bandit, pip-licenses, pytest

**Storage**: No persistent storage. Model files read from disk; audio output
is an in-memory tensor passed through the ComfyUI node graph.

**Testing**: pytest (unit tests for effects pipeline and chunking logic;
ComfyUI node integration validated manually via quickstart scenarios)

**Target Platform**: Windows 11, ComfyUI Desktop (port 8188). CI: Ubuntu
(standard GitHub Actions runner, no GPU, no torch).

**Project Type**: ComfyUI custom node (in-place loaded library)

**Performance Goals**: Generation time comparable to upstream (wall-clock
bounded by model inference, not our code). Effects processing instantaneous
for clips under 60 seconds.

**Constraints**: No system binaries. No vllm. No src/ layout (ComfyUI
constraint). pedalboard must handle all audio effects.

**Scale/Scope**: 3 nodes, ~5 source files after refactor. No scale concern —
single-user local tool.

### Source Code Layout (after rewrite)

```text
ComfyUI-Lyra/
├── __init__.py          # ComfyUI node registration (thin)
├── nodes/
│   ├── __init__.py
│   ├── loader.py        # OrpheusTTSModelLoader node
│   ├── generate.py      # OrpheusTTSGenerate node
│   └── effects.py       # LyraAudioEffects node
├── core/
│   ├── __init__.py
│   ├── model.py         # Model loading and device management
│   ├── inference.py     # Token generation pipeline (transformers + snac)
│   └── chunking.py      # Text chunking and audio concatenation
├── tests/
│   ├── test_effects.py  # pedalboard effects pipeline unit tests
│   └── test_chunking.py # Text chunking logic unit tests
├── pyproject.toml       # Updated with optional-dependencies split
├── requirements.txt     # ComfyUI Manager shim (generated from runtime extras)
└── uv.lock              # Updated after pyproject.toml changes
```

**Structure Decision**: `nodes/` holds ComfyUI interface classes (INPUT_TYPES,
RETURN_TYPES, FUNCTION, CATEGORY); `core/` holds the inference and DSP logic
with no ComfyUI imports. This separation allows testing `core/` without a
ComfyUI runtime. The existing `hf_auth.py` remains at root (used at import time
by `__init__.py`).
